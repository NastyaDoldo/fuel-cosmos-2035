# НАЧНИ ОТСЮДА — решение кейса «Топливный космоконтур 2035»

Репозиторий: https://github.com/NastyaDoldo/fuel-cosmos-2035
Постоянный сайт: https://fuel-cosmos-2035.streamlit.app

## Куда смотреть (по приоритету)

1. **ИТОГОВЫЙ_ОТЧЁТ_Топливный_космоконтур_2035.md** — весь кейс в одном файле:
   стратегия, цифры обоих сценариев, сравнение стратегий, риски, чувствительность,
   Монте-Карло, контракты, дорожная карта.
2. **docs/presentation.html** — анимированная презентация (16 слайдов, 1920×1080):
   открыть двойным кликом, листать стрелками, F — во весь экран.
3. **docs/speech.md** — доклад на 4 минуты с хронометражем по слайдам и ответами на вопросы жюри.
4. **docs/management_memo.md** — управленческая записка (та же база, формат кейса).
5. **README.md** — запуск и проверка.
6. **results/** — выгрузки: план по годам/каналам, KPI, проверки, сравнение сценариев,
   реестр рисков, чувствительность, Монте-Карло, сводный XLSX.

## Запуск (Python 3.10+)

```powershell
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
pip install -e .
python -m pytest -q                                   # 27 тестов
python -m fuelloop.cli run --risks --sensitivity --monte-carlo
streamlit run src/fuelloop/app/dashboard.py           # интерфейс оператора
```

## Ключевые цифры (воспроизводимы ядром)

- Стандарт: NPV 8023 млн, CAPEX 1430 (лимиты соблюдены), обслуживание 100%/100%, дефицит 0.
- Обязательный стресс: NPV 8419 млн, дефицит 151,1 т (2038–2040, показан честно),
  критический спрос 100% (политика critical_first), жёстких нарушений 0.
- Монте-Карло (n=1000, seed=42): P(крит. < 99%) = 0%.
